# Rigel 0.4.0-alpha.1

This is a pre-release. It is not `releases/latest`, and the updater's default feed does not offer
it to stable installs. Install it only if you want to try the new Graph surface and the refreshed
free-model roster.

## The code graph

- **Graph** in the rail opens a read-only map of the open project: files, top-level symbols,
  resolved relative imports and name references. Click a node for its neighbours; focus a file or
  symbol to keep the surrounding hops; choose depth 1–3.
- A background indexer fingerprints the project every 20 seconds. When files change it rebuilds
  the graph, writes `.rigel/codegraph.json` and updates the Graph header's age and counts.
- At most once every ten minutes, one live zero-priced OpenRouter row names up to eight
  architecture concepts for the indexed files. The prompt contains project-relative paths and
  top-level symbol names only. Concepts are kept only when they point at files the graph still
  contains, and a failed pass leaves the deterministic graph intact.
- The scan is bounded: 320 files, 512 KiB per file, 900 nodes, 2 400 edges. The surface reports
  truncation rather than silently hiding it.

See [codegraph.md](../codegraph.md).

## Models and free agents

- The live roster is refreshed every three minutes while the window is open, instead of only at
  launch or when the picker opens. Free rows that became paid, disappeared or arrived are reflected
  without a restart.
- Free mode still probes candidates before choosing; the new `free_agents` read returns the ranked
  zero-priced chat rows without sending a probe request.

## Updates and packaging

- The signed self-updater, the detached executable swap and the Windows installer path from the
  0.3 line remain in this build.
- Canonical repository links now point at `github.com/chuckiphone/Rigel`.

## Install

Windows 10 1809+ x64. The NSIS installer and MSI are attached to this release and listed in its
signed update manifest. Because this is a pre-release, `releases/latest/download/latest.json` stays
on the newest stable release.

## Known limits

- The graph is name-based, not type-checked. It is not a compiler index.
- Concept nodes depend on a configured OpenRouter key and a live free row; without either, the
  local graph still updates and the header says why the concept pass was skipped.
- The watcher follows one project at a time.
