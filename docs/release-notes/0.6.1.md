# Rigel 0.6.1 — stable

Rigel 0.6.1 is a fixes release on the 0.6 line. It removes two sources of window freezes, makes
the room's readiness polling cheap, gives the coordinator its project root, and completes the
permission matrix. No data migration is required.

## Window and chat performance

- **Free mode no longer freezes the window.** The command refreshed every configured provider,
  ranked the free rows and probed the candidates on the window's main thread; it now runs on the
  async runtime, so the button's “scanning free models…” state no longer comes with an
  unresponsive app.
- **The Chat tab no longer probes every harness on a timer.** Its two-second poll used to trigger
  a fresh 45–90 second headless probe per configured CLI whenever the one-minute cache expired,
  so the machine was almost always probing. The poll now returns the configured list plus the last
  measured readiness and never starts a probe. A real pass runs only when you ask for one:
  Settings → Harnesses → Check again (or `?force=1` on `/v1/room/harnesses`).
- **Every polled room command is async.** Status, roster, messages, attachments and harness reads
  no longer run on the window's main thread, and the control API's harness route runs its
  deliberate probe on a blocking worker instead of stalling the API runtime.

## Agents and permissions

- **The coordinator is told its project root.** The prompt used to say only “the current working
  directory”, so a coordinator asked for its root spent its steps searching for one and could hit
  the step limit without answering. Every coordinator and subagent prompt now names the absolute
  project root, and the verbatim `\\?\` prefix is stripped for readability.
- **The permission matrix is project-wide.** It now lists agents from every session, not only the
  session Settings has open. Muse's coordinator session therefore appears, custom roles such as
  `coordinator` and `muse` are labeled by name, and the tools only a custom role covers (MCP, web,
  mail) have an owner. The project grant remains the ceiling: a role or agent can narrow it and
  never widen it.
- **SkillSpector runs hidden.** The scanner is spawned with `CREATE_NO_WINDOW`, so a scan no
  longer opens an empty console window. Its output was already piped; only the window was visible.

## Approvals

- **A click can no longer be lost mid-write.** An answer is written to a completed temporary file
  and renamed into place, so a poll sees either no answer or a whole one. An answer that cannot be
  parsed is left in place rather than consumed, and a failed answer un-marks the card so it
  returns with its refusal and Retry state intact.

## Install

Windows 10 1809+ x64. The NSIS installer, MSI, raw executable, signed `latest.json` and SBOM are
attached to the release. This is a stable release, so `releases/latest` and the default stable
updater feed point at 0.6.1. The Windows installers are unsigned, so SmartScreen may warn; the
update manifest is Ed25519-signed and every published asset has a SHA-256.

## Known limits

- The Chat tab's harness readiness is from the last explicit re-check; a CLI installed or signed
  into afterwards shows as “not checked” until you press Check again.
- The Windows installers are unsigned; only the update manifest is signed.
