## Checks

- GitHub's asset digests match the manifest's three artifact hashes and the release table above.
- Downloading all five assets independently and running `sha256sum` reproduces each value in the
  table, including the public `latest.json`.
- Downloaded `latest.json` and ran
  `rigel update check --manifest latest.json` with the repository's
  `crates/rigel-app/resources/update-pubkey.txt`: `signed by the configured key · 0.6.0 → 0.6.0`.
- The release workflow ran `rigel update verify` against the NSIS, MSI and raw executable before
  creating the release.
- `gh release list` reports `Rigel 0.6.0` as **Latest**, and `releases/latest` resolves to
  `v0.6.0`. The release is neither a draft nor a pre-release.
- The four bundle jobs passed on the tagged commit, including the macOS and Linux bundles.

## Limits

- This release is Windows x64 only. The macOS and Linux bundles built in CI but are not published;
  macOS needs signing and notarisation, and no Linux package is verified for distribution.
- The Windows installers are not Authenticode-signed. Windows may show a SmartScreen warning; the
  update manifest is Ed25519-signed and every asset has a published SHA-256.
- `0.4.0-2` remains a historical pre-release. Its earlier receipt records `0.1.7` as Latest at that
  time.
