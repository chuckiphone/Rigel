## Limits

- This release is Windows x64 only. The macOS and Linux bundles built in CI but are not published;
  macOS needs signing and notarisation, and no Linux package is verified for distribution.
- The Windows installers are not Authenticode-signed. Windows may show a SmartScreen warning; the
  update manifest is signed and each asset has a published SHA-256.
- At the time of publication, `0.4.0-2` was a pre-release, so `releases/latest` remained on the
  stable `0.1.7` build.
